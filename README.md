# Calculadora Postfix con Pilas LIFO

## Descripción
Proyecto de Programación III enfocado en la implementación
manual de una pila enlazada (LIFO) para resolver expresiones
en notación postfix (polaca inversa).

## Objetivos
- Implementar estructuras de datos manualmente.
- Aplicar el funcionamiento de pilas LIFO.
- Resolver expresiones postfix.
- Desarrollar una aplicación móvil funcional.

## Tecnologías
- Java
- Android Studio
- Git y GitHub

## Estructura del Proyecto
- /docs -> documentación y UML
- /src -> código fuente
- /mockups -> diseños de interfaz

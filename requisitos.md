# Requisitos del Sistema

## Requisitos Funcionales

### RF-01
El sistema deberá permitir ingresar expresiones matemáticas.

---

### RF-02
El sistema deberá convertir expresiones infix a postfix.

---

### RF-03
El sistema deberá evaluar expresiones postfix utilizando una pila enlazada manual.

---

### RF-04
El sistema deberá mostrar el resultado de la operación.

---

### RF-05
El sistema deberá validar expresiones inválidas.

---

### RF-06
El sistema deberá permitir operaciones:
- suma
- resta
- multiplicación
- división

---

### RF-07
El sistema deberá mostrar visualmente el comportamiento de la pila.

---

# Requisitos No Funcionales

### RNF-01
El proyecto deberá desarrollarse utilizando Java.

---

### RNF-02
La aplicación deberá ejecutarse en Android.

---

### RNF-03
No se permitirá el uso de Stack de Java ni estructuras equivalentes.

---

### RNF-04
El código deberá estar documentado y organizado.

---

### RNF-05
El proyecto deberá utilizar control de versiones mediante Git y GitHub.

---

# Restricciones

- No utilizar estructuras Stack incorporadas.
- Implementar manualmente la lógica LIFO.
- Mantener separación entre lógica e interfaz.

---

# Alcance del Proyecto

El proyecto cubrirá:
- implementación de pila enlazada
- evaluación de expresiones postfix
- conversión básica infix → postfix
- interfaz móvil funcional

No incluirá:
- base de datos
- autenticación
- almacenamiento en nube
- cuentas de usuario
